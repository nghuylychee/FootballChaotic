## Open hypotheses (priority order)
1. **First-2s hook type: impact vs setup** (testing). If the first 2 seconds show an in-game hit instead of a setup frame, then stayed-to-watch rises, because Shorts viewers decide in about a second and a hit reads without any language.
   - Variant A (impact in frame 1): #1 = https://youtube.com/shorts/12pEl3F8qzI (cycle 1). Needs 2 more.
   - Variant B (setup first, payoff at ~3s): 0 so far. Unposted candidates already exist in `brag-output/` (said, diary, diver all open on a setup frame); none of them is on the channel yet.
2. **What drives geography?** Every Short so far gets 84–100% of its views from Vietnam (cycle 1 data). Candidates for later single-variable tests: posting time aligned to US/EU evening, English-only on-screen text (already true for the new clip), avoiding Vietnamese-trending tags. Now testing: metadata topic framing, D1 indie-gamedev vs D2 football-fan (batch 2, 1 Short each, both public 2026-10-29 18:25 GMT+7; not in the planned EU slot), and publish time, T1 Vietnam afternoon vs T2 EU evening (batch 3, 2 vs 3 Shorts, all D1 framing).
3. Lead with Cores / Ultimates / pitch rules instead of "football but you can punch". At least 3 other games use the punch angle (cycle 1 research), so it may not stand out. Raised by research, untested.
4. Title style: meme phrasing vs naming the mechanic. Untested.
