# Blue Lock review (2026-11-18)

Owner muốn game tham chiếu thêm Blue Lock để có góc marketing "anime bóng đá egoist". Review mọi Core + Tuyệt kỹ theo hướng đó.

- `cores-ultimates.xlsx`: tổng hợp 49 Core + 37 Tuyệt kỹ (lấy từ config ngày 2026-11-18, **trước** khi đổi), điểm Blue Lock fit 1–5, verdict, ý tưởng; tab `Blue Lock Review` = cách chấm + danh sách ưu tiên + lưu ý IP.
- Luật IP: tên trong game là tên riêng của mình, không dùng "Blue Lock", "Metavision", tên chiêu / nhân vật của bộ truyện.
